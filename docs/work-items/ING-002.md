# ING-002：可疑乱码文字层导入门槛

来源：COL-002 的 HU08 原件，16 页；页面可读，文字层因嵌入字体缺少 Unicode 映射而出现大量非空乱码。增强元数据识别不保证正文可检索。

本任务独立分支 `fix/ing-002-text-layer-review`，依赖 PR2 的扫描页门槛和 COL-002 基线。PR1 已合并；不修改正式或历史 dev 数据，不把乱码修复混入 PR2，也不修检索排序。

先用自写字体映射损坏 PDF 通过真实上传接口形成失败回归，再实现可疑文字层检查。只依据明显异常的非空字符信号（非空白控制字符、替代字符等），不使用英文词典或“不认识外语”作为判定依据。命中时暂停导入，列出页码，不生成片段/向量；原文件保留供查看、OCR或更换版本。正常多语言、数学、可读字体及少量杂字符必须有边界验证。

这不是全文自动OCR或全部乱码的检测证明。没有异常控制字符的错误字母映射、OCR近形错字及语义错误仍可能漏检；不把未命中称作已人工验证。通过阈值仅表示未发现该结构信号。

验证：固定干净提交，目标用例与继承回归分开；真实 HU08 原件及50份历史导入文件只读扫描，独立 TestClient 库模拟添加/重复/重试，对照三份运行实例快照。所有真实文件保持原 SHA，不入Git；候选独立 Draft PR，未经授权不合并。
