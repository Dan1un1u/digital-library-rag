本项以main `8174362` 为基线，独立分支 `fix/doc-002-chinese-fonts`。将手册字体统一为微软雅黑，保留命令中的Consolas；清除主题覆盖和日文字体回退，补全页眉页脚、表格与默认字体设置，并修复生成器，避免再次生成时回退。

保持原手册内容、结构、图片、字号和页面设置。Word与PDF一起更新；核对DOCX字体与PDF实际嵌入字体，渲染检查全部页面，保留前后字体统计与文件哈希。新PR保持Draft，未经授权不合并；不修改应用或馆藏。
