用户要求检索两类代表文献各 25 篇，按修复后流程模拟添加，观察新问题。用户随后明确环境为 dev。因此使用独立测试库，不修改正式 25 篇馆藏；沿用现有 Draft PR，暂不合并。

2026-10-19归属调整：本轮COL-002基线及ING-001迁到PR2，PR1只保留MQ修复及COL-001基础。以上“沿用现有PR”为历史指令，当前按[PR2迁移说明](../validation/COL-002/pr2-migration.md)隔离执行；原执行证据不回写。

## 冻结边界

- 被测业务逻辑保持 MQ-003/MQ-004 候选版本，不在本检测中修正新发现后再冒充首次通过。
- 采用目的抽样，兼顾经典地位、学科/方法覆盖与全文可获取性，不声称是引用量前 25 名；当前均为英文版本，中英文比例不作为验收项。
- 社科包括经济、社会、心理、政治、教育和传播；人文包括哲学、文学理论、史学和数字人文。译本、重印与原作日期分开登记，未证实的版本年份留空。
- 固定实际下载 URL、重定向、SHA256、页数、入选理由与来源核对方法；下载失败、非 PDF、错误讲义和替换记录单独保留，不计为应用缺陷。
- 原始 PDF 经当前 API 做真实 Luna 增强识别及可选 Crossref 查询。保存原输出再对比参考书目；不得先手工改值后声称程序识别正确。
- 原扫描文件保留，用作纯扫描及“封面有文字、正文扫描”的负例。需要时在应用之外制作 Windows OCR 副本，保留原/派生双哈希、处理页及可视内容校验；不声称应用自动支持 OCR。
- 文字层乱码、正文缺失、作者或年份误识别、无外部匹配、提供方超时分别统计。范围外的本机作者候选不重新列为 MQ 缺陷。
- 计划导入的是 50 篇不同文献，OCR 副本不另算新增文献。最终导入值如经应用外 AI 辅助核对修改，记录字段差异与依据，人工复核状态保持真实。

## 验证与证据

1. 独立进程和存储运行候选，接口返回被测源码和测试标记；存储及端口不得覆盖正式实例。
2. 50 次增强预览，核对模型状态、出版年审核与补全状态，并证明预览前后馆藏未变。
3. 对原始扫描/混合扫描和乱码文字层执行独立负例，记录成功/失败及实际正文覆盖，不能只看 ready。
4. 冻结审核后的批次计划，向 dev 库实际导入，再验证文献身份、页数、片段、检索、原文访问和重复导入。
5. 原始完整 PDF、OCR 副本和原始模型回执留在 D 盘工作区；PR 仅提交清单、去除机器路径和长正文的证据、分析与贡献台账。

本项不等同于整体验收、人工准确率评测或通用检索质量评测。发现新问题应保留失败结果，待后续另行修复。
