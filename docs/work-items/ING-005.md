# ING-005 批量入库的重复项提示

## 复现

- 在「上传与管理 → 批量入库」选择已有的 ENEC 和两份新 PDF。识别后，三份都默认勾选「本次入库」。发布结果均标为「可阅读」，实际只新增两条馆藏记录。
- 在同一批选择新 PDF 和它的改名副本。两份均提交识别和入库，结果均标为「可阅读」，两个原文链接指向同一条馆藏记录。

## 影响

馆员在审核和发布结果中无法确认哪些文件已存在、哪些是同批内的重复项。重复项也会进入逐篇识别。后端按文件内容保留唯一记录，混合批次中的原有元数据保持一致。

原始复现见 [ING-005 验证记录](../validation/ING-005/README.md)。

## 修复

批量页按 PDF 内容预先检查已有文献和同批副本。「已跳过的文件」显示每份文件的原因，已有文献附原文链接。识别和发布只处理本批需要入库的文件。若同一文件在审核期间已由其他会话入库，发布结果也会显示「这份 PDF 已在馆藏」。

见 [修复复测](../validation/ING-005/fix-recheck.md)。
