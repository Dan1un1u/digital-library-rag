# DEP-001 硅基流动兼容与本机接入隔离

用户要求交付项目继续使用最初的硅基流动接口，本机自建接入只留本地。本项独立于已合并的 MQ、ING、RET、UI 与 DOC 修复，分支为 fix/siliconflow-portability，目标 main，新建 Draft PR，暂不合并。

原 main bdfb737 的四项云端适配器仍可用，但一键启动无条件调用开发者 D 盘服务脚本，README 也将个人环境作为默认安装条件。项目还包含本机服务快照、配置写入器和代理适配器，其他成员无法按通用安装步骤复用。

本项移除个人服务快照、专用适配器及接入脚本；保留硅基流动原配置、HTTPS、Bearer 鉴权和请求协议。启动入口只启动项目，补齐首次运行目录创建并尊重真实配置的数据路径。新增18项兼容测试，与继承回归分开报告；移走的20项仅属于旧本机接入测试，不计作新功能或失败。同步根部署说明及图文手册，历史截图和原始证据不改写。

本机接入源码在仓库外备份；既有运行目录、模型、凭证、馆藏和服务不迁移。当前云端配置故意拒绝私有 provider；个人环境不能直接覆盖本项目配置。

验收要求：旧配置可装配四项云端服务；四条 HTTP 契约兼容；启动不调用个人服务；真实与 MOCK 库隔离；新增及继承回归通过；干净提交与证据一致；凭证和真实馆藏不入 Git。真实硅基流动账户在线响应不在本次离线验收范围。验证见[DEP-001记录](../validation/DEP-001/README.md)。
