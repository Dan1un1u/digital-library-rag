# QA-001 问答重排耗时与问题要点

用户在正式馆藏询问「我想了解旋转量化」，页面显示耗时 71.6 秒。「问题要点与回答范围」的三个要点显示同一句提示，一般向量量化的资料缺口只出现在正文后的范围说明。

问答先按现有本地相关性排序缩小解释类与查找类问题的模型重排候选。支持批量的重排器一次提交问题与机制两个任务，硅基流动单查询重排接口沿用原有调用方式。比较题保留两侧证据的候选。原文支持句继续按片段定位和校验。

要点对应关系和资料缺口随正文一次生成。服务端核对要点序号和结论位置，并恢复问题要点的原文。界面在每个要点下显示对应解释、原文链接和已知缺口。要点字段缺失或非法时，已通过引用校验的正文和整体范围说明可以照常显示。

测试证据见 [QA-001 验证记录](../validation/QA-001/README.md)。
