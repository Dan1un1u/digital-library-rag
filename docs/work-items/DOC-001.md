# DOC001 图文使用手册

用户要求检查项目是否已有使用文档，并补充图文并茂、带真实浏览器操作截图的说明。已有安装说明、模型说明与历史演示脚本，本项补充统一用户手册。

工作拆解与交付：核查现有说明和当前界面；建立独立演示馆藏；通过浏览器执行FQ-ViT增强识别、填写编目和真实导入；展示检索、问答、引用核验、正文审核和运行设置；撰写13节正文；以14幅实拍生成13页Word与PDF；逐页查看排版；记录截图、版本和输出哈希；在独立Draft PR中供审核。

制作过程发现UI001进度容器重复key，修复和4项新增回归仅归属PR6。文档分支依赖该修复，文档PR相对base只包含文档工作。527项全量测试属于UI001验证，DOC001不重复计作新增工作量。

验收口径：实际按钮名称与操作一致，明确当前PDF版本年份；区分预填和正文入库；如实说明外部服务、OCR和待核对状态；区分浏览器操作与接口准备；不假称旧实例已部署修复；每幅图有原始文件与哈希，Word/PDF完成逐页核验。核验明细在`docs/user-guide/verification.json`。
