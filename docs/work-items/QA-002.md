# QA-002 澄清选项重复提交

在「搜索与问答」输入「我想了解旋转量化」，选择一个澄清选项，点击「补充后重新提问」。进度进入「重排并选择正文及相邻证据」时，原版仍允许更改选项并再次确认。定向复现中，两次确认各自创建了一个后台任务。

等待和轮询原来都在提交按钮触发的页面执行中完成。页面重新执行时，进度仍可能显示在侧栏，程序却没有继续轮询原任务。旧的澄清表单也会继续接受提交。

修复后，第一次确认保存问题、选项、筛选条件和任务状态。问答处理期间，确认过的选项和提交按钮处于禁用状态。页面重新执行时会继续读取原任务的进度。若重新执行发生在后端接收提交之后、前端保存任务 ID 之前，重发同一次提交标识会取回已有任务。

收到回答后，页面显示结果并恢复提问。连接中断时，页面提示错误，保留已选内容供重试。前后对比及测试命令见 [QA-002 验证记录](../validation/QA-002/README.md)。
