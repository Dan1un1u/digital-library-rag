# MQ-006：新增馆藏缺失学科仍可入库

## 问题与范围

六篇自然科学文献在正式库显示“待分类”。原始批次只填写了 NPU、LLM、FPGA 等主题词，未填写所属学科。上传页面已有学科选项，但后台与批次工具未检查；旧记录的关键词推测又无法识别这六组题名与主题词。

本工作项在新dev库回放六份相同SHA256的PDF及当时已核对的元数据，先复现再修复。它检验元数据确认后的导入、正文解析、索引和分类，不重新评价增强识别模型的准确率。正式库及其他测试库不做修改。

## 改动

- 共用三个学科标签：自然科学、社会科学、哲学与人文科学。新增入库必须选择其中一项，主题词继续保留在 topics。
- 同步上传、异步上传、直接调用 Services.ingest 均在登记前检查；异步错误在排队前返回。
- 批次工具的 plan 和 apply 均检查学科，旧计划即使哈希有效也不能绕过。
- 识别预览不要求提前选学科；历史记录的读取和分类回退逻辑保持可用。底层 LibraryStore 仍支持历史记录与离线解析，不代表完成应用层的新馆藏入库。
- 更新清单模板、合成演示数据及旧测试的有效入库样本，使它们明确选择学科；旧测试原有的解析、年份和检索断言继续执行。

## 验收方法

1. 将六篇原PDF复制到独立输入目录，核对内容哈希。
2. 修复前使用原始清单导入空dev库，保留六篇待分类的结果。
3. 新增33项自动测试，保存修复前的失败记录和修复后的目标检查、全量回归。
4. 修复后用原始清单验证批次拒绝，以及六篇在两个上传接口的12次拒绝；数据库与索引不变。
5. 为六篇明确填写“自然科学”，再次导入空dev库；检查六篇就绪、零待分类、题名关键词/向量/混合检索共18次命中，以及重复导入不改变索引。
6. 对照其他运行库的前后快照，提交验证记录到独立Draft PR。PR以PR8为前置，不合并。

执行证据见 [MQ-006 验证记录](../validation/MQ-006/README.md)。
