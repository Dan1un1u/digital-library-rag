## 修改前后

| 场景 | 基线 | 验证提交 |
| --- | --- | --- |
| 混合扫描、文字层编码异常 | 原上传仍返回对应的 422，恢复列表返回 404。两条对照用例在读取恢复记录时失败 | 分别显示第 2 页和第 1 页，管理页生成定位到原 PDF 的页码链接 |
| 提交修正版 | 普通上传可登记可读副本，失败原件无法关联 | 修正版接受相同的正文检查，通过后入索引。重启后原件、修正版、提交时间和处理结果仍可查看 |
| 修正版仍不合格 | 在普通文献列表形成另一条独立的失败记录 | 归入同一恢复记录，显示失败理由和对应问题页，检索索引保持原状态 |
| 索引发布中断 | 普通导入可保留已经解析的内容 | 同一恢复记录保留待索引的副本和旧索引，重新提交相同字节后复用正文完成发布 |
| 旧库升级 | 2 版库保留原有诊断文字 | 迁移到 3 版后从历史消息恢复页码范围。已有可检索文献、片段、索引版本和原 PDF 字节一致 |
