# MQ-008 运行中回滚复验

复审基线为 `95a933d`。在独立馆藏中借助 SQLite 延迟约束让修订在提交阶段失败，并模拟恢复时暂时读不到旧索引。

| 核验项 | 复审基线或中间复现 | 最终候选 |
| --- | --- | --- |
| 索引回滚加载失败时查询 | SQLite 回到旧作者，搜索仍返回 HTTP 200 | 搜索返回 HTTP 503，恢复记录保留 |
| 索引可读取后重试修订 | 需要一致的数据库和检索版本 | 重新加载已提交索引后保存，搜索和文献详情使用同一作者 |
| 索引可读取后先入库另一篇文献 | 中间候选让旧恢复记录遗留，重启时撤回刚发布的索引 | 先恢复旧修订再发布，新增文献重启后仍可检索 |

修订、启动和索引重建共用恢复逻辑。修订已在 SQLite 提交后，临时清理失败可以留给下一次恢复。未能加载已提交版本时，服务暂时撤下内存里的检索快照，避免展示尚未提交的修订。

新增用例在独立库验证修订失败、重试和入库后重启。复测命令为 `python -m pytest -q app/tests/integration/test_metadata_review.py`。
