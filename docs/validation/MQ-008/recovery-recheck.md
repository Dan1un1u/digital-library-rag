# MQ-008 中断恢复复验

对照 PR20 的 `83e0eaf` 和修复提交 `424ebd4`。在两个独立库重放同一个断点，先写入更正后的检索索引，再模拟 SQLite 修订尚未提交时重启。自定义启动方式先加载磁盘索引，再把服务传给 API 工厂，与当前本机启动入口一致。

| 核验项 | 修复前 | 修复后 |
| --- | --- | --- |
| 文献详情作者 | Accepted Author | Accepted Author |
| 检索结果作者 | Uncommitted Author | Accepted Author |
| 对外检索版本 | 中断时留下的索引 | 上一次已提交的索引 |
| 待恢复记录 | 仍存在 | 恢复并加载后清除 |

默认启动与自定义启动均验证了回滚后的接口响应。恢复时若加载索引遇到临时错误，待恢复记录留给下次启动。若 SQLite 已提交，则重新加载已提交的索引并清理记录。

原分支的断点用例中默认启动通过，自定义启动失败。修复后元数据复核目标用例 **8 项通过**，全量回归 **640 项通过**。具体版本与响应见 [对照数据](recovery-recheck.json)。
