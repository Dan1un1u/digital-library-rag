# 负责人项目更新包

本包帮助负责人从项目最初版本更新到当前已合并成果，并获得175篇已录入馆藏。应用代码来自main `446f7b5a18b4ebdcc83638618827c802f0416be8`，保持原来的硅基流动接口。

## 交付内容

| 路径 | 内容 |
| --- | --- |
| 项目根目录与`app/`等 | main原样代码、测试及已合并文档，共583个版本文件 |
| `runtime/real/library.sqlite` | 175篇文献的元数据、分类、4037页正文、16699个片段与455条主题关联 |

负责人解压至新目录，按包内说明安装项目依赖、填写自己原有的硅基流动密钥并生成一次检索索引，再运行`Start-Library.ps1 -Mode real`。已有175篇文献和人工确认的元数据无需重新上传或识别。

## 原API兼容性

最初工程`lib_management_v1/lib_management/.env.example`与当前配置均使用`https://api.siliconflow.cn/v1`。问答与增强识别调用`/chat/completions`，向量调用`/embeddings`，重排调用`/rerank`。原`SILICONFLOW_API_KEY`、单独配置的`LLM_API_KEY`及空LLM密钥回退方式继续支持；新增provider字段省略时默认`siliconflow`。

本机正式馆藏现有索引由个人BGE服务生成，与硅基流动的后端身份和输入处理不同，因此更新包携带完整数据库及正文，由负责人使用原服务重建一次云端索引。重建前可以查看馆藏和原文，检索与问答要等重建完成。

- 对SQLite执行一致备份、完整性和外键检查，核对四张业务表逐行摘要；175份PDF逐份核对数据库内容哈希。
- 对原样导出的583个版本文件核对main内容，并从最终ZIP实际解压，核对每个文件的CRC和SHA256。

- 将实际解压数据库复制到独立检查目录，使用原始工程配置示例及交付配置分别装配服务，检查175篇列表、16699个待建索引片段及三类原文下载。

最终文件大小、SHA256及结果见[交付回执](result.json)与[应用读取检查](application-smoke.json)。18项请求契约使用拦截响应，实际云端请求为0；负责人账户的密钥、额度和模型响应由交接后首次重建确认。
