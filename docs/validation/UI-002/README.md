## 实现与发现

新增226条集中管理的界面译文，覆盖导航、学科显示、上传与编目、问答进度、已知错误和引用原文页。`lang=en|zh`随页面地址保存；无参数的新会话默认中文。输入区使用稳定的组件标识，切换语言会保留当前页面、筛选条件、搜索结果、回答、引用选择和上传草稿。文献原文、题名、作者、模型回答及后台学科值保持原语义。

浏览器发现首版在切换语言后，部分已选选项仍显示中文，虽然自动界面检查已通过。原因是浏览器保留了旧的格式化字符串。修复在切换时重新发送现有的后台选项值，让浏览器更新选中标签；新增一例检查选中值的更新标志和英文序列化结果。另将英文数量卡片改为数字显示，避免窄列中出现省略。

初始21例用于确认功能缺失；随后增加3例译文目录和引用接口检查，再增加1例浏览器发现问题的回归，共25例。开发时修正了AppTest查询参数返回标量的断言，并补充管理页面的小标题。中间运行保留在本机工作目录的独立输出中；本目录收录原始失败与最终通过结果。

## dev 操作范围

本轮API为19040、页面为19640，存储位于本工作目录的`runtime/UI-002/dev-library`，与原有实例分开。模型使用显式MOCK服务，所有PDF均为本轮生成的合成资料；本轮验证界面和操作状态，不测真实LLM回答质量。

实际操作包含：中英文导航往返、英文关键词搜索及结果保留、脚本问答与引用、原生文件选择上传、中文填写主题后切换英文、核对作者与版本年份并导入、查看就绪状态、英文超时提示和英文引用原文页。API复核新记录保留两位作者、2025版本年份和后台“自然科学”标签，用户输入的中文主题未被翻译。

原有18000、19000、19010、19020、19032五个实例均只读比较快照，文献记录和索引未变化；本轮未迁移、修改或重启它们。个人模型接线和凭证仍在仓库外。
