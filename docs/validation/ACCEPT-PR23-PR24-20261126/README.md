## PR24 重复确认

实时提交原问题时，模型直接生成回答。重复确认用例回放用户报告中的两条澄清选项，选择「机器学习中的旋转量化」，并向真实后端提交补充问题。在「重排并选择正文及相邻证据」阶段再次送入原确认事件。

运行中澄清选项和两处提交按钮均处于禁用状态。重复事件送入后只记录到一个后续任务，轮询沿用同一个任务 ID。该任务在 50.5 秒返回回答，主表单恢复提交。搜索方式在锁定和解锁时均保留用户选择，改为由会话状态初始化后，复测日志中没有出现控件默认值重复赋值警告。
