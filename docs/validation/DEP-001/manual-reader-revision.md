# 使用手册 1.2 修订记录

本次按用户要求更新现有 PR8，将手册改为面向使用者的操作说明。Markdown 与 Word 同步更新，当前为11页、13幅配图。

## 内容调整

正文按打开系统、浏览、搜索、上传、编目、查看状态、提问和阅读原文组织。删除其中的个人模型名称、开发端口、PR与提交历史、测试口径及重复的警告，保留会影响具体操作的信息，如重新识别会覆盖表单字段。常见问题集中给出处理方法。

原手册中的部署历史、截图环境和开发验证信息由维护记录承接，不再穿插在读者的操作流程中。原始记录保留于 [首版配图记录](../../user-guide/verification.json)、[原文档验收](../../user-guide/acceptance-20261019.json)和[DEP-001先行验证](results.json)。这些记录对应各自的版本。

## 配图和排版

撤下读者手册中的系统设置图，该图包含个人模型配置。正文沿用其余13幅原始操作截图，不改动截图文件。生成器按图片文件选择版面宽度，使章节重排后仍保持合适的尺寸；原先两处Word局部裁切继续使用原图。

Word重新生成并由Microsoft Word导出阅读用PDF，再用文档技能的render_docx.py与Poppler生成逐页图。11页均检查正文、图注、表格和页脚；核验与当前输出哈希见 [本次检查](manual-reader-revision.json)。PDF及页面图保存在本工作目录 reports/DEP-001/manual-reader-revision/，用于排版检查。
