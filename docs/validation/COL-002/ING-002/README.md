# ING-002：乱码文字层导入门槛

结果：候选已通过验证，独立 Draft PR 依赖 PR2，暂不合并或部署。原馆藏和历史 ready 记录不自动迁移；本修复暂停可疑输入，不自动恢复其正文。

## 原因与修改

HU08 原件的 Type0/Identity-H 嵌入字体缺少 ToUnicode 映射。页面显示可读，提取结果却将字形编号当成字符，例如首字母和空格错位，大量控制字符占每页约15.9%–17.4%。PyMuPDF 按坐标排序还会将部分异常码替换成空格，使原 raw_text 检查进一步失去证据；排序后的段落仍含乱码，原非空判断允许索引。

新增语言无关的 `text-layer-encoding-v1` 门槛：原始顺序提取后检查非空白 C0/C1 控制字符与 U+FFFD；一页至少8个且比例至少2%时要求核对。段落清洗和原文偏移策略保持原规则；解析器版本升级为 v4。解析/保存两处边界均检查，防止绕过诊断列表。命中后返回 TEXT_LAYER_REVIEW_REQUIRED、页码和核对/OCR/更换版本说明；文献登记 failed，不保存正文或片段、不构建向量，管理界面显示“待核对正文（未加入检索）”，原文件可读。

不使用英文词典、不按语言判乱码；正常中文、阿拉伯语、希腊符号、数学、私用字形、空白和少量杂字符均有不阻断控制。没有异常控制码的错误字母映射、近形 OCR 错字和语义错误仍可能漏检。本门槛不是全文 OCR 或一般可读性认证。
