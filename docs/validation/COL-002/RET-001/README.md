# RET-001：为正文向量保留题名上下文

候选验证通过，独立 Draft PR 依赖前置 MQ-005 PR；只增加本项检索表示、测试与证据，暂不合并部署。

## 原因与修改

原纯向量检索仅编码片段正文，关键词索引同时包含题名/主题。以完整题名查询时，正文片段可能不重复题名；HU11原top5漏检，扩大top20可找到，但不是原门槛下的通过。

候选将每个正文片段编码输入改为 `Title: <文献题名>\n\n<原片段>`，查询仍按原查询编码。vector模式仍只按向量相似度排序，没有暗用关键词或强制置顶。正文文本、片段ID、页码、偏移和引用保持原值，不创建虚构题名片段。

索引retrieval_config新增固定 `vector_text_policy=document-title-prefix-v1`，加载时核对；旧的纯正文表示不能冒充新表示复用，返回明确的不兼容和重建提示。必须在独立环境构建候选索引；正式/历史实例不迁移。
