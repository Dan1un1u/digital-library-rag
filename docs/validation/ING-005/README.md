# ING-005 批量入库复测

2026-11-26。测试源码为 `da912d65b206e406e15589aafe0138fc89bf924d`，来自 PR #28。起始馆藏为正式库的一致副本，包含 176 篇就绪文献和 16,745 个正文片段，索引版本为 `idx_20261126T142957_e9e87a2e98dc`。

用 Chrome 在独立本机端口复测已有 ENEC 与两篇新文献的混合批次，运行真实增强识别。后续使用该测试库的独立副本，以 Streamlit AppTest 操作实际表单并调用相同后端，覆盖同批改名副本、扫描页与取消勾选。补测直接调用批量任务接口，验证重复提交、损坏文件和数量上限。除已有 ENEC，其余 PDF 为合成测试样本。

| 用例 | 实际结果 | 结论 |
| --- | --- | --- |
| 已有 ENEC 与两份新 PDF | 三份均完成增强识别，分别给出 2、4、4 个主题候选。确认后新增两篇，保存人工修改的题名、年份和主题，保留 ENEC 原记录和元数据，只发布一次索引。页面将三份都标为「可阅读」 | 入库通过，重复项提示缺失 |
| 同批提交新 PDF 和改名副本 | 发出两个识别任务，两项默认勾选。馆藏只新增一条，页面显示两项「可阅读」，两个链接指向同一份原文 | 后端查重通过，重复项提示缺失 |
| 混合扫描件、有效 PDF 和取消勾选项 | 结果指出扫描件第 2 页缺少可用文字层，有效 PDF 正常入库，取消勾选项无馆藏记录 | 通过 |
| 重复提交全为已有的批次 | 返回既有条目，索引版本一致 | 通过 |
| 同批包含损坏 PDF 与有效文件 | 损坏项返回 `INVALID_PDF`，同批已有有效文件仍可用 | 通过 |
| 单批选择 11 份 PDF | 页面和 API 都拒绝超过 10 份的批次 | 通过 |
| 核对新增馆藏 | 独立测试库达到 180 篇、16,753 个正文片段。新增四篇均可检索，下载的原文哈希与输入相同 | 通过 |
