## 装配契约与后续 C 接入

A/B 构造和所有核心方法保持共同契约。D 先用 A.normalize_config 获取实际 tokenizer revision，把相同切块参数交给 B 的 settings；A.ingest_pdf 接收原始统一配置，由 A 自身规范化。CLI 预导入的配置须与当前 .env 一致，否则明确报不兼容，不自动转换字段。未固定的云修订为 null。

应用的 create_app(settings=None, services=None) 可显式注入 Services。Services 持有一次性 A/B/C 实例及 RLock；上传、重建、读取、搜索与整个 ask 互斥，一次问答不混用版本。后端只启动一个进程；离线 seed/rebuild 前停止后端。B 自身负责原子索引指针，D 只有 build 成功后才将新文献 indexing→ready；失败保留 indexing 和错误。D 不访问 B 的私有快照。

C 需提供 `dlrag.qa.engine.QAEngine(retriever,llm_client,settings)` 与 `ask(dict)->完整 AnswerResponse`。共同规格未约定真实 LLM 适配器的类名/构造器，所以 D 不猜名称；使用显式扩展配置 **LLM_CLIENT_FACTORY=module:function**：

```python
# 由 C 或后续联调者在其适配器所在模块提供；D 当前不创建这个实现。
def create_client(settings):
    # 用 C 实际客户端类，接收 settings.llm_base_url / llm_model /
    # llm_api_key.get_secret_value() / llm_timeout_seconds。
    # 返回满足 generate_json(system_prompt: str,user_payload: dict)->dict 的对象。
    ...
```

之后设置 `LLM_CLIENT_FACTORY=dlrag.qa.<实际模块>:create_client`。这是 D 的装配扩展点，不改变 C 的核心 QAEngine 接口。当前尚未确认适配器函数名，不能直接照抄占位字符串运行。C 依赖仍需合并；D 已把 prompts/*.txt 纳入未来包资源。缺配置/模块时健康检查保留缺项，操作返回准确错误。

默认 C settings：planning_enabled=true、retrieval_mode=hybrid、retrieval_top_k=20、max_evidence_chunks=6、context_budget_tokens=6000、max_output_tokens=1000、max_answer_repairs=1。C 必须自行按真实服务上下文限制核验预算。规划开关可用于 baseline 比较。

## API 示例与说明

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
$body=@{query='BM25';mode='keyword';top_k=20;filters=@{topics=@('合成测试')}} | ConvertTo-Json -Depth 5
Invoke-RestMethod -Method Post http://127.0.0.1:8000/search -ContentType 'application/json' -Body ([Text.Encoding]::UTF8.GetBytes($body))
$body=@{question='那个系统';history=@()} | ConvertTo-Json
Invoke-RestMethod -Method Post http://127.0.0.1:8000/ask -ContentType 'application/json' -Body ([Text.Encoding]::UTF8.GetBytes($body))
```

上传通过 UI 或 /docs 的 POST /documents（multipart file、metadata_json）。客户端不能设置 doc_id、状态或服务器文件路径。缺标题标待核验；rights_note 默认待人工确认。上传错误、超限、类型不支持分别 422/413/415；未就绪与超时 503。A/B/C ProjectError 按 code/message 属性映射，类身份不要求相同。C 仅 status=error 才当业务失败；其余结果可含 error=null。

可选 **GET /documents?include_nonready=true** 是 D 为本地管理视图增加的显式查询参数，默认 false，原定公开请求/响应不变。没有新增公共重建接口；重试经停止后端后的本地脚本。反馈 rating 接受 useful/not_useful，本地追加 JSONL；没有账户系统，不对外部署。

问答每次校验完整契约和引用 ID；片段、年份、页数等字段不静默改名。未知输出扩展字段可保留，未知输入字段拒绝。自动结构合法只证明引用能解析，不替代 C 的来源校验与人工语义核验。PDF 原文件通过受控目录+doc_id 提供，浏览器页跳转/高亮未验收。
