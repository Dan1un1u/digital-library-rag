# 12–15 分钟课堂展示提纲

| 负责人 | 时长 | 内容与应能解释的检查 |
|---|---:|---|
| A | 3 分钟 | 专题范围、来源与使用说明；PDF→规范页→Chunk；偏移与去重；双栏/扫描限制。展示一个真实测试或解析问题 |
| B | 3 分钟 | BM25、向量、RRF 与过滤；同一快照、重载与失败保留旧索引；说明相似分数不是可信概率 |
| C | 3 分钟 | 意图与澄清、证据选择、引用核查；一个引用存在却不支持结论的失败案例。C 已交付；结合实际调用记录说明规划失败和证据不足案例 |
| D | 4 分钟 | 三页界面、上传状态、四类问题、点击引用核对原文和 PDF；统一配置与评估；演示后续真实模式所需配置 |
| 全组 | 1–2 分钟 | 实验设置与局限、回答问题；报告只用经过复核的数据与真实运行 |

离线备用展示真实 A/B + fake embedding + 脚本问答的接口流程；real 模式已经装配 C。自动测试属于工程行为检查，不是真实问答实验题。60 个候选题已汇总，但尚未经全员复核与冻结。真实检索/回答指标与人工语义指标暂不展示数字；以真实实验完成后的报告替换占位，不沿用 A/B 附件中的历史成绩冒充本次总体实验。

每人准备一张“输入→处理→输出”说明、一个测试和一个限制。现场网络故障时切换明确标识的 mock，先说明切换，再展示交互，不把替身当模型结果。
