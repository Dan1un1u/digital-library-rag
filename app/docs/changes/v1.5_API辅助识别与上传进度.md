# v1.5 API 辅助识别与上传进度

日期：2026-10-18。

## 改动

上传页新增默认开启的“增强识别（推荐）”。在真实服务中，使用已配置的硅基流动密钥和 `Qwen/Qwen3-VL-8B-Instruct`，结合 PDF 前两页的图像、文字和本机候选信息，辅助识别完整主副标题、有序作者名单、出版年份、语言及 DOI/arXiv 来源。前两页图像最长边约 1400 像素，文字每页最多 6000 字符；不上传整本 PDF，不读取外部网页。

结果只预填表单，保留用户核对和编辑步骤，不自动修改已有馆藏。字段展示识别来源、页码和支持摘录。API 失败、未配置或候选非法时保留本机结果，提示超时、鉴权、限流、网络/服务或格式问题；不展示密钥、异常正文或服务商响应内容。关闭增强识别后仅在本机识别；演示服务不调用真实 API。

标题要求保留副标题；作者校验排除常见单位名称，并容忍 PDF 分栏提取导致的姓名词之间混入邮箱。字段校验包括类型、范围、受限来源链接和候选与所给摘录的对应关系。图像识别及摘录仍为模型候选，不等同于人工核验。

## 进度

识别和导入使用后台任务，前端每 0.35 秒读取进度，显示当前阶段和实际经过时间：

- 识别：接收 PDF → 读取文献信息 → 准备页面图像 → API 识别 → 校验结果 → 完成。
- 导入：接收 PDF → 等待馆藏处理 → 解析正文 → 处理文献、准备搜索 → 保存信息 → 完成。

进度条百分比对应已进入的处理阶段，不伪装成模型内部或文件传输字节进度；等待 API 时用时持续更新。API 失败后的完成状态明确说明仅完成本机识别。浏览器上传控件继续显示自身文件上传状态，前后端均限制单份 PDF 的大小。

后台任务最多 2 个在途、单工作线程，保留最多 16 项记录，完成后 15 分钟过期。进度查询使用独立锁，不被正文处理期间的馆藏锁阻塞。临时 PDF 在任务结束后清理。

## 配置与接口

新增配置 `METADATA_API_ENABLED=true`、`METADATA_API_MODEL=Qwen/Qwen3-VL-8B-Instruct`、`METADATA_API_TIMEOUT_SECONDS=45`，示例写入 `.env.example`。密钥继续从 `SILICONFLOW_API_KEY` 读取，本次没有把密钥写入配置文件。

- `POST /documents/metadata`：保留同步预览，新增 multipart `use_api` 开关。
- `POST /documents/metadata/jobs`：提交异步识别。
- `POST /documents/jobs`：提交异步导入，原同步导入接口保留。
- `GET /document-jobs/{job_id}`：读取阶段、历史阶段、用时及结果。

本次仅辅助识别编目信息，未新增扫描 PDF 的全文 OCR 入库能力；扫描页可以辅助识别标题作者，但正文无法提取文字时仍需先对全文进行 OCR。重复 PDF 仍沿用既有去重及保留旧元数据的规则，预览不会直接修订已入库记录。

## 验证

- 全量自动测试 307 项通过，2 项已有警告。覆盖扫描页识别、关闭 API、演示模式不联网、失败保留本机结果且不泄露异常、候选校验、多栏作者、异步导入、队列容量、过期与临时文件清理。
- 真实 API：纯图片版 Longformer 约 5.5 秒识别出标题、3 位作者、2020 年和 arXiv 链接；Attention Is All You Need 完整识别 8 位作者，校验复测约 18.6 秒。
- 当前中文论文《企业化经营何以推动新型农村集体经济有效运行？——基于甘肃省前进牧业的案例研究》识别出完整主副标题、范志雄/程名望/徐辉、2026 年及 DOI；浏览器复测约 10.2 秒，进度达到 100%，结果已预填，未提交入库。
- 浏览器曾遇到一次 API 暂时失败，本机回退提示正常；后续重试成功。上述样例时间只代表本次测试，不构成速度保证。
