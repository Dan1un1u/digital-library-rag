# v1.5.1 页面切换与任务进度重置

日期：2026-10-18。

修复第二次任务及切换页面后，回答进度沿用上一轮阶段、耗时和完成提示的问题。

- 主导航、馆藏二级导航、管理二级导航变化时，通过导航回调清除上一轮问答进度、回答、搜索结果、引用选中状态，以及上传文件的临时预填状态；已入库文献不受影响。
- 每次提交搜索或问答，在页面重新运行前先清除旧结果和进度；新的问答在发送请求前立即显示从 0 秒开始的等待状态。提交或轮询连接失败时恢复空白进度提示。
- 进度区域每次更新先清空，并使用任务编号和阶段组成独立界面标识，避免上一轮长列表的勾选阶段残留到新任务的短列表。
- 更换、移除 PDF 或重新识别时，清除上一文件的识别候选、作者等表单字段和成功提示；同一文件正常编辑时保留修改。

这里重置的是前端临时状态，不删除馆藏，也不撤销已提交的后台任务。已经开始的导入仍会在后台完成，可到文献管理查看。

验证：新增连续两次提问、提交请求前状态清理、主导航往返恢复空进度、二级导航清除识别预填的回归测试；扩展上传测试验证移除文件后表单清空。全量自动测试 310 项通过，2 项已有警告。

实现：`src/dlrag/ui/state.py`、`src/dlrag/ui/app.py`。
