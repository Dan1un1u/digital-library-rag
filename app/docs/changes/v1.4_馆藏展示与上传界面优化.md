# v1.4 馆藏展示与上传界面优化

日期：2026-10-18。

## 导航与页面

- 左侧三个主入口：馆藏展示、搜索与问答、上传与管理。
- 馆藏展示下设“馆藏文献分类”和“热门电子文献资源”。分类页展示三大学科的篇数、饼图和可按学科筛选的文献列表；资源页展示可点击的 PDF 首页封面卡片。
- 上传与管理下设“上传文献”“文献管理”“系统设置”，默认直接进入上传文献。选中文件后仍自动识别标题、作者、年份等，用户核对并选择学科后点击“导入文献”。后台自动完成原有处理流程。
- 模式说明、当前模型、当前索引及详细配置仅在二级“系统设置”显示。模式沿用现有后端启动配置切换方式，该页面提供切换说明，没有新增会即时切换服务的按钮。
- 移除问答中的“是否有帮助”及反馈表单；反馈后端接口保留兼容。
- 移除主页面运行模式横幅、回答和搜索结果中的索引版本，以及建立索引、重试、总体评估的操作与命令。问答实际进度、引用超链接、原文高亮保留。
- 搜索方式改用中文显示，筛选条件收纳在左侧折叠区域。新增馆藏引导区、统一卡片及适配浅色/深色主题的样式。

## 分类口径

三大学科为自然科学、社会科学、哲学与人文科学。上传时必须选择学科，作为现有 topics 中的显式标签保存，无数据库迁移。显式标签优先；历史资料按题名及主题关键词辅助判断。无法确定或标签冲突的文献列为待分类，不分摊到饼图中，单独提示数量；因此三类之和可能小于馆藏总数。

当前真实馆藏 12 篇均为计算机、语言模型及信息检索资料，辅助归为自然科学；社会科学及哲学与人文科学均为 0，统计与实际馆藏一致。

## 封面来源与性能

新增 `GET /documents/{doc_id}/cover`：验证文献及原文件路径后，在本机渲染 PDF 第一页，返回 PNG；最长边约 640 像素。缓存最多 48 张，按文件路径、修改时间和文件大小区分，浏览器私有缓存 5 分钟；图片懒加载。不请求模型、不下载外部封面、不修改原始 PDF。点击整个卡片在新页打开对应 PDF。

“热门电子文献资源”当前为精选馆藏展示，按年份倒序、同年按标题排序。系统没有阅读热度统计，页面已明确说明其顺序不代表访问量排名。

## 验证

- 独立 `.venv` 环境运行全量自动测试：300 项通过，2 项已有警告（TestClient 依赖提示及重复 PDF 元数据保留提示）。
- 新增分类唯一性、显式标签优先、未分类、封面 HTML 转义、封面接口与原文件不变、二级导航和设置隐藏的测试；更新上传预填和问答引用测试，验证学科标签保存、新文件重置及反馈 UI 移除。
- 真实后端：12 篇文献的封面请求全部返回 200 / image/png，单张约 70–123 KB。
- 浏览器核对分类数量、饼图、封面卡片、上传页面及二级设置；真实服务和当前馆藏保持可用。

相关实现：`src/dlrag/ui/app.py`、`src/dlrag/ui/library.py`、`src/dlrag/api/covers.py`、`src/dlrag/api/routes.py`。
