## 引用核验路径

搜索与问答 → 问答 BM25 → 点击结论下 `[1] 查看原文` → 展开同编号原文卡片 → 检查标题、原文及 PDF 文件页序 → “打开 PDF 原文件”。后台 /chunks/{chunk_id} 与 evidence.quote、pdf_page 一致，/documents/{doc_id}/file 返回同一原文件。自动测试已核对这些对应关系；**浏览器实际 #page 自动跳转未人工验收**。不支持跳转时按显示页号手动定位；未实现原页高亮，不能宣称已高亮。

## 管理与故障步骤

1. 上传坏 PDF：应 422，管理页看到 failed 与具体原因，不能显示 ready。
2. 上传重复 PDF：不新增文献与 Chunk，保留原元数据；不在冻结后重新生成样例文件。
3. 运行 real 但无模型：/health 标 not_ready、问答 503，界面有中文提示。不要改成 mock 后继续声称真实效果。
4. 复现模拟超时：问题“超时”，应 MODEL_TIMEOUT；用户可重试，不显示虚构结论。
5. 索引构建失败：旧索引仍能搜索，新文献保留 indexing 与错误。停止后端，修复配置，执行 `python scripts/seed_demo.py --rebuild-only`，再启动。
6. 后端未启动：UI 显示无法连接；检查终端与 API_BASE_URL，启动后刷新。端口冲突先停旧进程。

离线备用：使用明确标记的 mock 与合成资料展示交互；真实实验报告未执行时展示限制和待办，不展示伪造成绩。允许课前录屏，但本次没有伪造或生成录屏证据。
